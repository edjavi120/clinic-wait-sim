4 · About this exhibit

This is the site guide. The chatbot (bottom right) reads exactly this text and nothing else.

Data: synthetic, generated by a discrete-event clinic queue simulation written for this exhibit (train_model.py). No real patient data. Model: scikit-learn MLPRegressor, exported to JSON and run in your browser. Chat: WebLLM. · Source code & training script
